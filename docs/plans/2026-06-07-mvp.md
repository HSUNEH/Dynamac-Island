# Dynamac Island MVP Implementation Plan

> **For Hermes:** Use test-driven-development and systematic-debugging. Keep each step small, verify with Swift tests, and avoid private macOS APIs in MVP.

**Goal:** Build an open-source macOS Dynamic Island-style notch overlay for ST's MacBook Pro M1 14-inch.

**Architecture:** Native Swift package with a reusable core library and a macOS AppKit/SwiftUI executable. The core owns state, event reduction, timing, and notch geometry so it can be tested without launching UI. The app shell will later host an always-on-top transparent panel centered on the built-in display notch.

**Tech Stack:** Swift 6, Swift Package Manager, XCTest, SwiftUI/AppKit for macOS runtime.
